Transcript

  1. Satchel packs a practice set into one HTML file. The questions and answers in this demonstration are fictional.
  2. Write questions in plain text. These three include a typed fraction, a multiple-choice question and a number.
  3. A missing answer key blocks download. Correcting the question makes the complete set available again.
  4. Download the actual HTML file. The recording then opens that file with network access disabled in the browser.
  5. This downloaded set is about 32 KB. It opens directly from a file; no account or installation is needed.
  6. Hints, larger text and high contrast keep the unfinished answer. Here, 5 is deliberately the wrong answer.
  7. Reload the same file and continue at question 1. The unfinished answer is restored in this tested Chrome browser.
  8. Checking shows the right answer and explanation. The other two answers are correct, including 1,000 with a grouping comma.
  9. The result is 2 of 3 right. Reloading preserves the completed attempt, and the missed question can be practised again.
  10. Save a real text report while offline. It records checked answers, explanations and hint use; the copyable view contains the same text.
  11. Retry only the missed question. The answer 1/2 is accepted as equivalent to .5; the retry is labelled separately.
  12. A report can be saved or copied for the learner to share. Nothing is handed in automatically. These are practice records, not verified grades.

Recorded from the current local production build in Chrome. The script checks the displayed results and reads the downloaded HTML and report files. No HTTP requests were observed after network access was disabled. All questions and answers are demonstration inputs, not learner records. Local-file storage and device support vary; this is not a learning-outcome study.
